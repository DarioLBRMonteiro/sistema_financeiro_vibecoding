# Inventário de insumos do projeto

| Arquivo | O que é | Usado pelo sistema em execução? | Onde será usado | Observações |
|---|---|---|---|---|
| `FSD.md` | Documento de Especificação Funcional e Técnica (FSD). | Não | N/A (Apenas documentação) | Define a arquitetura MVC, regras de negócio, tabelas do banco de dados e fluxos do sistema. |
| `DESIGN.md` | Guia de Design System e especificação visual (Admin Logic). | Não | N/A (Apenas documentação) | Define os tokens de cores, tipografia, bordas, espaçamentos e componentes visuais. |
| `code.html` | Protótipo estático do Dashboard desenvolvido em TailwindCSS. | Não | Referência para front-end | Serve como modelo visual e estrutural para a conversão de layouts e estilizações para Bootstrap 5 e Vanilla CSS. |
| `cursoemvideo-logo.ico` | Arquivo de ícone (Favicon). | Sim | Favicon do sistema em execução | Deverá ser copiado para a pasta pública de assets (ex: `public/assets/images/` ou raiz de `public/`) durante a implementação. |
| `screen.png` | Captura de tela do Dashboard do protótipo estático. | Não | Referência visual | Imagem que ilustra o layout esperado para a interface principal do painel financeiro. |
